About This Project

What is BrooklineForward?

BrooklineForward is a small project by Brookline residents to make the town's public financial data and documents easier to find and explore. The town publishes a lot of detailed information about its budget, planning, and finances. We're trying to pull it together in one place with interactive charts and plain-language summaries.

This is not an official town project and we don't speak for the town or any committee. We're just residents who find this stuff interesting and think it's worth making more accessible.

Where the data comes from

Everything on this site comes from publicly available Town of Brookline sources. The budget charts are built from data in the town's published financial plans, adopted budgets, and Long Range Financial Plan. Every chart includes a source citation, and every document in the library links back to the official source.

We don't have any special access to data. If you can find it on the town's website, that's where we got it too.

What this is not

This is not a policy proposal, a lobbying effort, or an advocacy group. We're not trying to tell anyone what Brookline should do. We're trying to make it easier for residents to see what the town's own data shows and form their own opinions.

How to contribute

  • Spot an error in the data? Open an issue on GitHub
  • Know of a town document we should include? Let us know in an issue
  • Want to suggest a chart or visualization? We'd love to hear it
  • Want to contribute code? The whole project is open source on GitHub
